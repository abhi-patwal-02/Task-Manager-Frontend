## ✨ Features

### 🔐 Authentication & Onboarding

* Signup & login system
* Instant auto-login after signup
* JWT stored securely

---

### 👥 Team Management

* Add/remove members using email search
* Role switching (Admin / Member)
* Admin-only controls

---

### 📁 Project Dashboard

* View all projects
* Create new projects
* Grid/List toggle views

---

### ✅ Task Management

* Create tasks with due dates
* Assign tasks to members
* Status tracking

---

### 🧠 Smart Task System

* Subtasks (auto-generated from description)
* Progress tracking with visual bars
* Auto-complete tasks

---

### ⏰ Overdue Detection

* Tasks highlighted if overdue
* Visual badges for urgency

---

### 👤 Member Profiles

* View assigned tasks
* Pending vs Completed separation
* Timestamp tracking

---

### 🔔 Notifications

* Toast-based feedback system
* Action confirmations

---

### 📊 Analytics Dashboard

* Total tasks
* Completed tasks
* Pending tasks
* Overdue tasks

---

### 🎨 UI/UX Highlights

* Tailwind CSS modern design
* Glassmorphism effects
* Smooth animations
* Hover interactions
* Loading indicators
* Responsive layout

---

## 🛠️ Tech Stack

* React (Vite)
* Tailwind CSS
* Axios
* React Router
* React Hot Toast
* Vercel (Deployment)
